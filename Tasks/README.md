## Other Harbor supported datasets

All datasets at [Harbor Hub Datasets](https://hub.harborframework.com/datasets)
are also supported as registry tasksets. See
[SWE-rebench-v2-TaskTrove/](./SWE-rebench-v2-TaskTrove/) for a third-party
registry example.
